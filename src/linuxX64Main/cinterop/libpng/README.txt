Unmodified libpng 1.6.59 API headers from https://github.com/pnggroup/libpng/tree/v1.6.59.
pnglibconf.h is scripts/pnglibconf.h.prebuilt from that release.
The upstream license is included in png.h.

These headers allow the normal Linux Kotlin compilation on Windows hosts without Linux system headers.
No libpng implementation is bundled. Linux executables dynamically link the system libpng16 runtime.
