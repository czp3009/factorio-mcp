Unmodified turbojpeg.h from libjpeg-turbo 2.1.5.1:
https://github.com/libjpeg-turbo/libjpeg-turbo/blob/2.1.5.1/turbojpeg.h

The header is included for Kotlin/Native cinterop on every development host.
Its BSD-style license is retained in the header. No codec implementation is bundled.
Linux binaries dynamically link the distribution's libturbojpeg.so.0.
